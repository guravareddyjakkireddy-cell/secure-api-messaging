# secure-api-messaging
Spring Boot project implementing JWT authentication, role-based authorization, secured REST APIs, and Kafka/RabbitMQ asynchronous messaging integration.
## Objective
The objective of Week 7 is to secure REST APIs using Spring Security and JWT token-based authentication, implement role-based access control, and add asynchronous communication using Kafka or RabbitMQ.

## Technologies Used
- Java
- Spring Boot
- Spring Security
- JWT
- REST APIs
- Kafka / RabbitMQ
- Maven
- MySQL / PostgreSQL
- Postman

## Features Implemented
- Authentication and Authorization
- JWT Token Security
- Role-Based Access Control
- Secure REST APIs
- Kafka / RabbitMQ Messaging
- Endpoint Testing
